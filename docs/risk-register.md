# 项目风险登记表

| ID | 风险 | 影响 | 概率 | 缓解措施 | 状态 |
|---|---|---|---|---|---|
| R01 | JSON 数据存储只适合单 JVM 演示，多个 Tomcat 实例同时写入可能导致数据竞争。 | 高 | 中 | 部署文档声明单实例；未来迁移 SQLite/MySQL。 | 已缓解，仍需监控 |
| R02 | 跨表操作没有数据库级事务回滚，部分写入失败可能造成业务不一致。 | 高 | 中 | `executeAtomically` 保证 JVM 内互斥；关键操作已集中在 Service；未来引入预写日志或事务数据库。 | 已识别 |
| R03 | 公开演示入口误写真实数据。 | 高 | 低 | `/admin/database` 已限制为 Admin 且受 CSRF 防护；不作为正式业务联调基线。 | 已缓解 |
| R04 | CSRF 攻击导致用户在已登录状态下误提交。 | 高 | 低 | 全局 `CsrfFilter` 校验 `_csrf` 或 `X-CSRF-Token`。 | 已缓解 |
| R05 | 密码找回被滥用重置他人 TA 密码。 | 高 | 低 | 公开页面不再修改密码；管理员在 `/admin/users` 中处理重置。 | 已缓解 |
| R06 | AI 排序或建议存在偏见，被误用为录用决定。 | 高 | 中 | UI 免责声明、服务端同意校验、`AI_REQUEST` 审计；文案声明 AI 仅供参考。 | 已缓解，仍需人工复核 |
| R07 | 第三方 Qwen API 不可用或未配置。 | 中 | 中 | AI 功能可选；无 key 时按钮禁用；核心招聘流程和规则匹配可继续使用。 | 已缓解 |
| R08 | 上传文件伪装扩展名或被浏览器直接渲染。 | 高 | 中 | 校验扩展名、MIME、文件头；下载使用 attachment 和 nosniff。 | 已缓解 |
| R09 | 依赖漏洞或安全缺陷未被自动化工具发现。 | 中 | 中 | 已补安全单元测试；后续引入 OWASP Dependency-Check/Semgrep/SpotBugs。 | 待增强 |
| R10 | 需求与接口契约漂移。 | 中 | 中 | 更新接口契约和集成清单；高风险变更同步测试。 | 持续监控 |

## 复审节奏

- 每个 Sprint 结束前复查高影响风险。
- 任何认证、授权、上传、AI、数据存储改动后立即复查相关风险。
- 发布前运行 `mvn test`，并人工检查风险状态是否仍然准确。
